## Grocery Sales Performance-Excel

## Project Overview
This is an Excel practice project focused on analyzing retail sales performance and understanding how Excel can be used 
to answer business questions.

## purpose
The main purpose of this project was to practice using Excel for business analysis and develop the ability
to move from business questions to analysis , insights, and recommendations

## Dataset
The dataset used in this project is sourced from kaggle:
 **Dataset Name:[Supermart Grocery Sales - Retail Analytics Dataset]
 **Author :[Mohamed Harris](https://kaggle.com)
 **Description: This dataset contains simulated historical sales transaction data for an e-grocery application based in
  Tamil Nadu, India.

## Business Questions
**What are the total sales and total profit?
**How many orders were placed?
**Which category generates the highest sales?
**Which region performs best?
**Which sub-categories generate the highest sales?
**How do sales change over time?
**How do sales and profitability compare?

## Excel Skills Used
**Data cleaning and organization
**Excel Tables
**Formulas and calculations
**Pivot Tables
**Pivot Charts
**KPI calculations
**Profit Margin analysis
**Sorting and filtering
**Business insights and recommendations

## Key Insights
**Eggs, Meat & Fish generated the highest sales among the categories.
**The west region generated the highest sales.
*Krithika and Amrish was the highest-sales customer in the analysis.
**Soft Drinks generated the highest sales among the top sub-categories analyzed
**Snacks generated the highest profit, closely followed by Eggs Meat & Fish .
**Overall profit margin was approximately 25.05%
